# Student Enrollment & Course Management System (SECMS)

A Salesforce-based Student Enrollment & Course Management System designed to centralize student, course, instructor, and enrollment management.

## Project Overview
SECMS manages the academic enrollment lifecycle, including student registration, course management, enrollment requests, instructor assignment, approvals, fee tracking, reporting, dashboards, and security.

## Technology Stack
- UI: Salesforce Lightning
- Logic: Salesforce Flows
- Database: Salesforce Custom Objects
- Automation: Validation Rules, Flows, Approval Process
- Reporting: Salesforce Reports & Dashboards

## Main Objects
- Student
- Course
- Instructor
- Enrollment

## Key Features
- Student and course management
- Enrollment request and approval workflow
- Automatic instructor assignment based on course category
- Enrollment date and follow-up task automation
- Fee-paid validation before approval
- Reports for students, enrollments, pending approvals, and revenue
- Dashboard for student status, enrollments, revenue, and pending approvals
- Role-based security using profiles, permission sets, and sharing settings
