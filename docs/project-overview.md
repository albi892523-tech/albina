# SECMS Project Overview

## Problem Statement
The project addresses manual and fragmented enrollment operations where student and enrollment data may be scattered across systems. The proposed solution centralizes these processes in Salesforce.

## Purpose
The purpose of SECMS is to replace manual enrollment processes with a scalable, automated, and secure Salesforce solution supporting:
- Accurate student data management
- Structured enrollment workflows
- Automated approvals and validations
- Transparent reporting and monitoring

## User Roles
- Administrator
- Enrollment Officer
- Instructor

## Customer Journey
1. Awareness & Registration
2. Course Selection
3. Enrollment Request
4. Fee Payment
5. Approval
6. Instructor Assignment
7. Reporting & Completion

## Functional Requirements
- FR-1: Student Management
- FR-2: Course Management
- FR-3: Enrollment Processing
- FR-4: Instructor Assignment
- FR-5: Reporting and Dashboards

## Non-Functional Requirements
- Usability
- Security
- Reliability
- Performance
- Scalability
- Availability
